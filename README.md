Panduan Lengkap Aplikasi Rekapinyu

MENU KASIR

➤ Tombol Keyboard, Sebelum Angka 1 (Untuk Isi/Input Produk)

➤ Enter Untuk Memasukan Produk Ke Keranjang, Atau Klik dengan Mouse di produk)

➤ Tombol Atas ↑ & Bawah ￬ (Untuk Memilih Produk DiKeranjang)

➤ Tombol Kanan → & Kiri ← Pada Produk (Untuk Menambah dan Mengurangi Total Produk), Atau Manual Menggunakan Mouse.

➤ Icon Bluetooth >ᛒ Untuk Menghubungkan dengan Printer Bluetooth (Jika icon Bluetooth Berwarna Merah artinya Bluetooth belum tersambung, Jika Berwarna Hijau Artinya Bluetooth tersambung dengan printer Bluetooth)

➤ Tekan Enter ➥ Untuk Menyimpan/Mencetak Transaksi.

MENU PRODUK KASIR

➤ Icon Backup Warna Biru di pojok kanan bawah (Untuk Membackup Data Produk) Disarankan Rutin Membackup data Produk, Jika Menambahkan Produk baru.

➤ Buat Folder Dikomputer Anda Beri Nama Backup Produk (File yg Sudah Dibackup Pindahkan Ke Folder Backup Tersebut, buat jaga Jaga)

➤ Icon Import Warna Hijau di pojok Kanan Bawah (Untuk Mengimport/Memasukan Kembali Data yang sudah di Backup di Folder backup Produk)

➤ Usahakan Rajin / Rutin Membackup Data ketika Menambahkan Produk Baru.

➤ Kehilangan data bukan Tanggung Jawab Developer, Developer Sudah Menghimbau.

MENU SETING

➤ Atur Nama Toko, Alamat Toko, Nomor Handpone (Untuk Dicetak Di Struk)
