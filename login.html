Panduan Lengkap Aplikasi Rekapinyu

MENU KASIR

  1. ➤ Tombol Keyboard, Sebelum Angka 1 (Untuk Isi/Input Produk)
  2. ➤ Enter Untuk Memasukan Produk Ke Keranjang, Atau Klik dengan Mouse di produk)
  3. ➤ Tombol Atas ↑ & Bawah ￬ (Untuk Memilih Produk DiKeranjang)
  4. ➤ Tombol Kanan → & Kiri ← Pada Produk (Untuk Menambah dan Mengurangi Total Produk), Atau Manual Menggunakan Mouse.
  5. ➤ Icon Bluetooth >ᛒ Untuk Menghubungkan dengan Printer Bluetooth (Jika icon Bluetooth Berwarna Merah artinya Bluetooth belum tersambung, Jika Berwarna Hijau Artinya Bluetooth tersambung dengan printer Bluetooth)
  6. ➤ Tekan Enter ➥ Untuk Menyimpan/Mencetak Transaksi.

MENU PRODUK KASIR

  1. ➤ Icon Backup Warna Biru di pojok kanan bawah (Untuk Membackup Data Produk) Disarankan Rutin Membackup data Produk, Jika Menambahkan Produk baru.
  2. ➤ Buat Folder Dikomputer Anda Beri Nama Backup Produk (File yg Sudah Dibackup Pindahkan Ke Folder Backup Tersebut, buat jaga Jaga)
  3. ➤ Icon Import Warna Hijau di pojok Kanan Bawah (Untuk Mengimport/Memasukan Kembali Data yang sudah di Backup di Folder backup Produk)
  4. ➤ Usahakan Rajin / Rutin Membackup Data ketika Menambahkan Produk Baru.
  5. ➤ Kehilangan data bukan Tanggung Jawab Developer, Developer Sudah Menghimbau.

MENU SETING

  1. ➤ Atur Nama Toko, Alamat Toko, Nomor Handpone (Untuk Dicetak Di Struk)
